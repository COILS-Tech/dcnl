# Hero Carousel Images

Add your beautiful worship and community images here to display in the rotating background carousel on the home page.

## Required Images

The carousel expects the following images:

1. **worship-1.jpg** - Image of people worshipping
2. **worship-2.jpg** - Another worship scene (hands raised, singing, etc.)
3. **worship-3.jpg** - Another worship/prayer scene
4. **community.jpg** - Community gathering, conference, or meeting scene

## Image Specifications

- **Format**: JPG or PNG
- **Recommended Size**: 1920x1080 pixels (or higher resolution)
- **Aspect Ratio**: 16:9 works best
- **File Size**: Optimize images to be under 500KB each for faster loading

## Tips for Best Results

- Use high-quality, well-lit images
- Ensure images have good contrast for text readability
- Images will have a dark overlay applied automatically
- The carousel auto-rotates every 5 seconds
- Images will smoothly fade between transitions

## Adding More Images

To add more images to the carousel, simply:
1. Add your image files to this folder
2. Update the `images` array in `/app/page.tsx` with the new file paths
