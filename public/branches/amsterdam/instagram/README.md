## 📥 How to Download Instagram Images

### Method 1: Screenshot (Easiest)
1. Open the Instagram post on your phone or computer
2. Take a screenshot
3. Crop to just the image
4. Save with the filename above
5. Upload to `/public/branches/amsterdam/instagram/`

### Method 2: Instagram Download Tools
1. Copy the Instagram post URL
2. Use a tool like:
   - **DownloadGram**: https://downloadgram.com/
   - **Insta-Download**: https://insta-download.com/
   - **SaveInsta**: https://saveinsta.app/
3. Paste the URL
4. Download the image
5. Rename to the filename above
6. Upload to `/public/branches/amsterdam/instagram/`

### Method 3: Browser Developer Tools
1. Open Instagram post in browser
2. Right-click image → "Save image as..."
3. Rename to the filename above
4. Save to `/public/branches/amsterdam/instagram/`
